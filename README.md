# Scotland Street Lamp Import

Scripts and data for the [Scotland Street Lamps](https://wiki.openstreetmap.org/wiki/Scotland/Import/Street_Lamps) import into OpenStreetMap.

- `sources` - raw data
- `cleaned` - data converted to GeoJSON and duplicate points removed
- `output` - the GeoJSON files to be imported, created by `tag_lamps.py`
